# C 알고리즘 문제 정리

각 폴더는 Visual Studio 프로젝트 파일과 소스 코드를 함께 포함합니다.

| 번호 | 폴더 | 주제 | 소스 파일 | 핵심 개념 |
|---:|---|---|---|---|
| 1 | Algorithm_001 | 1부터 N까지 합 | Algorithm_001.c | 재귀 함수, 누적 합 |
| 2 | Algorithm_002 | 팩토리얼 계산 | Algorithm_002.c | 재귀 함수, 종료 조건 |
| 3 | Algorithm_003 | 피보나치 수열 - 재귀 | Algorithm_003.c | 재귀 호출, 중복 계산 |
| 4 | Algorithm_004 | 피보나치 수열 - 반복문 | Algorithm_004.c | 배열, 반복문, 동적 계획 기초 |
| 5 | Algorithm_005 | 최대공약수 GCD | Algorithm_005.c | 유클리드 호제법, 재귀 |
| 6 | Algorithm_006 | 선형 탐색 | Algorithm_006.c | 배열 순회, 조건 검색 |

| 9 | Algorithm_009 | 삽입 정렬 | Algorithm_009.c | key 값 이동, 부분 정렬 |
| 10 | Algorithm_010 | 점수 순위 계산 | Algorithm_010.c | 중첩 반복문, 순위 산정 |
| 11 | Algorithm_011 | 이진 탐색 | Algorithm_011.c | 정렬 배열, 재귀 이분 탐색 |

## 학습 순서

1. 재귀 기초: Algorithm_001 ~ Algorithm_003
2. 반복문과 배열 활용: Algorithm_004 ~ Algorithm_006
3. 기본 정렬: Algorithm_007 ~ Algorithm_009
4. 응용 탐색과 순위: Algorithm_010 ~ Algorithm_012

## 참고

- `x64/`, `Debug/`, `.vs/`, `*.obj`, `*.exe`, `*.pdb` 같은 빌드 결과물은 저장소 `.gitignore` 규칙으로 제외됩니다.
- GitHub에는 소스 코드와 Visual Studio 프로젝트 설정 파일 중심으로 올라갑니다.
